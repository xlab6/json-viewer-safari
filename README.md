# JSON Viewer for Safari

[English](README.md) | [简体中文](README.zh-CN.md)

A Safari Web Extension that automatically detects JSON pages and formats them for reading.

Requires macOS + Xcode; Node ≥ 18 only for the tests and the icon script.

## Features

- **Automatic takeover**: triggered by a JSON `Content-Type` or a body that is a single
  `<pre>` / plain-text JSON; real HTML pages are never touched, files > 8 MB are skipped
- **Formatted output**: syntax highlighting with line numbers
- **Links**: URLs inside string values look exactly like plain text until you hold ⌘/Ctrl
  and hover one — clicking opens them in a new tab; a plain click never navigates away;
  the URL in the top bar is click-to-copy
- **Monospace font picker**: lists every monospace font installed on your system
- **Theme**: follows the system light/dark setting or pinned to dark/light, persisted
- **Top bar**: request URL (middle-ellipsised when long) + render timestamp +
  size · lines · keys · depth (nesting levels, root = 1)
- **Back-to-top button**: appears bottom-right after scrolling past 300 px
- **Copy / download .json**; parse failures show the error message together with the raw text

## Quick Start

### Run in Safari

1. Open `xcode/JSON Viewer/JSON Viewer.xcodeproj` in Xcode and keep **Sign to Run Locally**
   for both targets
2. `Cmd+R` — the welcome window shows the current version and the repository address
3. Safari → **Settings → Extensions**: enable *JSON Viewer* and set website access to
   **All Websites**
4. Open any URL that returns JSON; for local files you can serve them:

```bash
python3 -m http.server 8000
# then open http://localhost:8000/demo/sample.json in Safari
```

### Build from the command line

```bash
cd "xcode/JSON Viewer"
xcodebuild -project "JSON Viewer.xcodeproj" -scheme "JSON Viewer" -configuration Debug build
```

## Development & Testing

```bash
npm install      # jsdom only
npm run check    # JS syntax + manifest lint
npm test         # smoke tests (150 assertions)
npm run icons    # regenerate every icon after swapping the logo
```

Tests cover: takeover boundaries (including pages that must not be hijacked),
rendering / line numbers / highlighting, link behaviour and click policy, both font
channels, system theme following, top bar / back-to-top, manifest and version-sync contracts.

## Xcode Project

The project was generated **without** `--copy-resources`, so it references the
`extension/` sources directly — edit, hit `Cmd+R`, done. To regenerate it:

```bash
xcrun safari-web-extension-converter ./extension \
  --project-location ./xcode --app-name "JSON Viewer" \
  --bundle-identifier cn.oxzz.json-viewer \
  --swift --macos-only --no-open --no-prompt --force
```

> After regenerating, check `PRODUCT_BUNDLE_IDENTIFIER`: the app must be
> `cn.oxzz.json-viewer` and the extension `cn.oxzz.json-viewer.Extension`, otherwise
> the build fails with `Embedded binary's bundle identifier is not prefixed`.
> Also keep the `nativeMessaging` permission in the manifest, or font enumeration stops working.
